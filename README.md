# Logistics & Supply Chain Dashboard | Microsoft Excel

## 📌 Project Overview

This project demonstrates the use of Microsoft Excel to analyze logistics and supply chain data through a structured dashboard.

The objective is to organize operational data into meaningful summaries and visualizations that help users explore logistics performance, compare categories, and understand patterns within the available dataset.

The project showcases spreadsheet-based analysis, data preparation, performance reporting, and dashboard design in a supply chain context.

## 🎯 Project Objectives

- Organize and analyze logistics and supply chain data.
- Summarize operational performance indicators.
- Explore trends across available dates, categories, or locations.
- Compare logistics metrics across relevant dimensions.
- Present operational information through charts and summary tables.
- Demonstrate Excel skills applicable to data analytics and operations reporting.
