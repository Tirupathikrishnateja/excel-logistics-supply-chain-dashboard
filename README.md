# Logistics and Supply Chain RFM Cohort Dashboard

## Overview
An Excel dashboard for logistics and supply-chain analysis using KPI and cohort/RFM-style views. Explore the worksheets and charts to review the measures and trends presented.

## Tools
- Microsoft Excel
- Dashboard visuals, worksheet calculations, and KPI reporting (as present in the workbook)

## Files
- `Logistics_Supply_Chain_RFM_Cohort_Dashboard.xlsx` — the project workbook.

## How to review
1. Download the workbook from this repository.
2. Open it in Microsoft Excel (desktop recommended).
3. Review the worksheets, formulas, pivot tables, charts, and any filters/slicers included.
4. Add screenshots to this README after confirming the workbook displays correctly.

## Data and validation
Verify data permissions and review formulas/hidden sheets before sharing.
